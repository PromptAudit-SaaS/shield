# Support

For setup questions, use this repository's Discussions. Search existing threads first. Include the package/version, operating system and relevant client/runtime version, with fictional inputs only.

For reproducible defects or bounded proposals, use the issue forms. See CONTRIBUTING.md for development and pull-request checks. Report vulnerabilities privately following SECURITY.md, never in a public discussion.

This is community support, with no promised response time or SLA. A protocol test or configuration example does not establish compatibility with every client release. Supported patterns may miss sensitive data or flag benign input; restoration returns originals to its caller. No certification or complete protection is claimed.
